# PennyTrack

A personal expense tracker built with Python to record and manage income and expenses.

## Planned Features

* Record income and expenses
* Categorize transactions
* Store transaction dates and descriptions
* View transaction history
* Calculate total income, total expenses, and current balance
* Save data between application sessions

## Technologies

* Python
* Tkinter (GUI)
* SQLite (database)

## Project Status

Currently in development.
